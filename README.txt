RIYACHAT EDUCATIONAL TRUST WEBSITE — STARTER FILES

Files:
- index.html: website content
- styles.css: responsive navy, white and gold design
- script.js: mobile navigation, year and email-app enquiry form

Preview:
Open index.html in a browser.

Publish free:
1. Create an account on GitHub.
2. Create a new public repository (for example, riyachat-trust-website).
3. Upload index.html, styles.css, and script.js to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish the site and use the URL shown in Settings > Pages.

Notes:
- This is a static starter site; it does not have a backend or database.
- The enquiry form opens the visitor's email app. It does not deliver messages automatically and has no inbox until you connect a real form service or backend.
- Add verified contact details, official trust registration information (when available), and genuine project photos before public launch.
- The school is described as a proposed project planned for 2028. Keep that status accurate and update it as plans change.
- Google Fonts require internet access; system fallback fonts are used if unavailable.
